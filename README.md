# Cosmopolitan Dental Care

A polished, responsive, nine-page static website inspired by the supplied dental clinic reference. Built with semantic HTML, CSS and vanilla JavaScript. No build dependencies.

## Preview

```sh
python3 -m http.server 8080 --directory dist
```

Open http://localhost:8080. Deploy `dist/` to any static host. All routes are actual `.html` files and work without server rewrites.

## Pages and interactions

Home, About, Treatments, four treatment detail pages, Contact and Privacy. Includes responsive keyboard-accessible navigation, treatment links, exclusive FAQ accordions, restrained entrance animation, image hover motion and reduced-motion support.

The appointment form **prepares an enquiry only**. It sends and stores no information. Visitors copy the prepared enquiry and choose whether to send it to the clinic using the official Instagram profile. A live booking backend is not configured.

## Content provenance

Clinic name, founder handles, focus areas and the Maps link were verified from the clinic's public Instagram profile on 24 November 2026: https://www.instagram.com/cosmopolitan_dental_care/ . No unverifiable address, phone, opening hours, practitioner qualifications, reviews, promotions, prices or patient statistics have been invented. General treatment copy requires clinic review before public marketing use.

Photography is illustrative and does not represent actual clinic staff, patients or premises. Hero photograph generated with the built-in image generation tool. Supporting photographs: Unsplash photo IDs `photo-1629909613654-28e377c37b09`, `photo-1606811971618-4486d14f3f99`, `photo-1609840114035-3c981b782dfe`. Google Fonts: DM Sans and Libre Caslon Display.

## Design

Reference-led clinical blue (#086eb5), deep navy (#102b3e), ice blue (#edf6fc) and white. Large Caslon headlines balance clear sans-serif navigation. Full-width patient photography, quiet grid layouts, contextual motion, careful mobile typography and responsive image compositions.
